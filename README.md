# COMP90018 Tutorial Archive

An archive of University of Melbourne Mobile Computing Systems Programming tutorial material from 2019, including slides, historical exercise archives, and Android example projects.

## Requirements

A slide/PDF viewer for teaching material. Android examples require Android Studio and tool versions compatible with each project’s own Gradle files.

## Getting started

Browse the relevant week’s `Slides/` and `Source Code/` folders. Open an individual Android project in Android Studio rather than treating the archive root as one Gradle project.

## Project structure

| Path | Purpose |
| --- | --- |
| `Week0 - Preparation` | Initial setup slides |
| `Week1 - Intro, Android Studio, git` | Introductory Android and Git material |
| `Week2 - UI, WatchOS` | UI and lifecycle examples |
| `Week3 - Threads, Service` | Threading and service examples |
| `Week4 - Sensors, Maps` | Sensors and mapping |
| `Week5 - Data Storage` | Persistence examples |
| `Week6 - Connectivity, Firebase` | Networking and Firebase |

## Configuration and limitations

This is historical teaching material; Android SDK, Gradle, Firebase, and service APIs may have changed. Preserve original exercise sources when making a modernized copy.

## Development and validation

Build and run the selected example with its own toolchain. Any example-specific tests live inside that project; there is no root-level archive test suite.
